FruitySelia has no account, login, subscription, purchase, advertising, analytics, or network service. It opens the native document camera on first launch. If camera capture is inconvenient, cancel it and use Import to select an image or PDF. OCR, barcode detection, cleanup, redaction, signing, and PDF generation run on-device. Recent scans are disposable local working copies. The app requests Photos access only after the reviewer chooses a Photos save or deletion action. Protect Recent Scans is off by default and uses system device-owner authentication when enabled. Visual signatures are document marks, not cryptographic signatures.
